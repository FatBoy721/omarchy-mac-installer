# M5 Apple Silicon contributor and source inventory

This is a point-in-time inventory of contributors and source references linked from [`omacom/linux-aurora` issue #293](https://github.com/omacom/linux-aurora/issues/293), plus the exact source snapshots reviewed for the J714s normal-system candidate. GitHub reported 66 comments at the source snapshot time, 2026-11-09 16:33 UTC; the connected issue-comment fetch returned all 66. The source pass recorded 101 unique URL strings as discovery leads and checked selected repositories, branch heads, pull requests and source files. Some URL strings were mentions, attachment links or duplicated/garbled Markdown, and not every link was examined. This is a useful, maintained inventory, not an exhaustive search of the internet or a closed-world link audit.

The maintained J714s integration record and its source closure are in [Integration/M5/J714s-Normal-System](Integration/M5/J714s-Normal-System/README.md), including the [metadata-only 15-package manifest](Integration/M5/J714s-Normal-System/candidate-package-manifest.json). The external branches and commits below are historical source identities; the central installer checkout is the project integration home.

**Evidence key:** `tested` means a public hardware result is described; `reported` means a contributor-authored claim or result that this review did not reproduce; `PR` means proposed upstream integration only; `offline` means source/data analysis with no board result. Hardware results below are not this review's hardware validation. GitHub repository license metadata is not a legal opinion; `NOASSERTION` or missing means file-level notices and licensing still need review before redistribution.
